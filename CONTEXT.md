# pc-keeper

Обслуживание Windows-машины одной командой: обновления программ и драйверов, аудит, контроль и освобождение места на диске C.

## Язык

### Диск C

**Чистка**:
Удаление заведомого мусора, который приложения пересоздадут сами: временные файлы, кэши, корзина, старые версии программ.
_Не говорим_: очистка, уборка

**Перенос**:
Перемещение тяжёлой папки с C на D (`D:\c-offload\<ключ>`) с junction на старом месте: данные остаются доступны по прежнему пути, а место на C освобождается.
_Не говорим_: offload, выгрузка, миграция

**Цель переноса**:
Папка из списка переноса вместе со своим ключом и процессами, которые должны быть закрыты на время переноса.

**Замер**:
Снимок размеров наблюдаемых папок и свободного места на C в один момент; ряд замеров — история, по которой видно, что выросло.
_Не говорим_: сканирование, аудит диска
